CISCO SWITCH MANAGER - ATUALIZACAO v0.2 -> v0.3

1. Pare a versao atual:
   docker compose down

2. Faça backup do diretorio data da v0.2:
   cp -a data data-backup-v0.2

3. Extraia a v0.3 em um novo diretorio.

4. Copie o diretorio data da v0.2 para a v0.3.
   Preserve especialmente:
   - data/csm.db
   - data/secret.key
   - data/backups/

5. Copie/ajuste o .env e acrescente, se desejar:
   CSM_PORT_POLL_INTERVAL_SECONDS=900
   CSM_PORT_HISTORY_RETENTION_DAYS=30

6. Suba a v0.3:
   docker compose up -d --build

7. Verifique:
   http://IP_DO_SERVIDOR:8080/health

A tabela interface_samples sera criada automaticamente no primeiro start.
